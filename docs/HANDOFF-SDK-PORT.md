## Build, install, test
```
./build-sdk.sh test        # release identity build + tests/run.sh + host_sim (its "silence" WARN is expected)
./build-sdk.sh beta        # build/beta-project/build/"sd88me - VST - JV-880 2 Beta"
python3 tools/make_tui.py --preview
tools/package.sh           # release zip
```
- **ROMs:** the tests need your ROMs (`JV_ROMS`, default `~/roms/jv880`). `tests/data/legacy-1.0.9.chunk` is built from the
  v1.0.9 sources and is gitignored, because it holds factory patch bytes.
- **Live III:**
  1. Run `python3 $MPC_SDK/tools/mpc_remote.py 192.168.2.217 update --yes <beta folder>`.
  2. Before that, copy the ROMs into `<beta folder>/jv880-roms/roms/` and delete any `*:Zone.Identifier` files.
     `update` replaces the whole folder, so save `jv880-favourites.dat` first and put it back afterwards.
  3. Run `... restart`. ASK THE OWNER BEFORE EVERY RESTART: unsaved work is lost.
- **Force:**
  1. Tar the beta folder into `/sdcard/Synths/`.
  2. With the MPC app stopped (`systemctl stop acvs`), run `tools/sdk/jv2_register.sh` with `tools/plugin_list.awk`. They are
     copied to `/tmp` and edit `pluginList-arm`, uid `4a563842`.
  3. Run `systemctl start acvs`. Ask first.
- **Remote screen (Live III):** `ssh -L 6721:127.0.0.1:6720 root@192.168.2.217`, then the addin's MCP at
  `http://127.0.0.1:6721/mcp` (screenshot, tap, drag). The owner often uses the device at the same time; stop and ask
  if the screen changes on its own. After a restart, an addin-restore script may restart the MPC app once more.

## Facts learned on hardware
- Skin Buttons toggle: a tap on a lit button sends 0. Bank and patch tiles fire on the rising edge only. Front-end
  momentaries (RANDOM, +FAV, −FAV) drop back to 0 from the worker.
- No readback while a value is being dragged: the worker skips a parameter for 300 ms after the host last moved it
  (`hostAt_`). Without this, the envelopes "never registered".
- Envelope widget: handles are 26 px. `highlightColour` paints the active stage, so keep it faint. Style the pressed
  handle in LCD ink.
- The MPC's Q tag (about 36 px) covers the top-left of the active Q-Link block, so the first column of each screen starts
  30 px in.
- MPC fonts render smaller and lighter than the previews. BANKS uses 22 px for banks and 21 px for patches.
- A display update after +FAV/−FAV is needed for the PRESET list names. Whether it also sends the page back to PLAY was
  not settled (the owner was using the device at the same time).

**B2. Late additions (2026-11-12, after user feedback; tested by the owner on the Live III beta)**
- The WAVE NUMBER cell shows the number (from 1) and name from the ROM's wave table: internal = 129 entries from `rom2+4`,
  an expansion card = the table from its header (0x84, end at 0x80), 60-byte entries, name first.
- Third press of a TONE key = WAVES page: 24 name tiles a page per tone (`wavetile_<t>_<n>`, `wavepage_*`; params 514-621,
  622 in all). The wave number steps one wave at a time (`nudge_pct` 2) and stops at its table's end.
- Wave group: real patch data only uses 0 (internal) and 1 (the card); the keys keep the upstream labels INT-A / INT-B / EXP-A /
  EXP-B. One card is loaded at a time, so a patch cannot mix cards (noted in the release notes).
- Release builds log the first 20 audio underruns (then every 100th) to the journal. None on the Live III in a play test.
  Clicks heard there fit the emulator reset on a card swap (cuts sounding notes); a fade before the reset would fix it
  (not built). Not tested on the Force: its MPC app was stopped by a Force Link switch during the check.
- Open from the feedback: patch +/- and jog sometimes not responding (looks like which control the MPC points them at).
- The betas (JV8B) are installed again on both devices (Force: registered in MPC.settings, backup `.bak-jv2-*`); remove them
  before release.
